mmuneej.Store setup
From download to your first product

Make it your store.

A one-time setup. Then manage everything through the visual admin. No code or JSON editing.

Before choosing your live host

The files are technically compatible with GitHub Pages. However, GitHub Pages policy prohibits sites primarily used for commercial transactions. Use a static host that permits sales for a live business; the GitHub publishing admin works with the same repository. Pages setup below is for a compatible demo, not confirmation of permission to sell there.

01

Upload the complete website

Extract the downloaded ZIP on your computer. Open your GitHub repository → Add file → Upload files. Drag all the extracted files and folders into the upload area, then commit.

Your repository must show these items at the top level:

index.htmlproduct.htmlcontact.htmladmin/assets/data/

Upload the contents of the ZIP, including folders. Uploading the ZIP itself does not install the website. The assets folder includes the design, scripts and product images.

02

Choose the publishing source

For a GitHub Pages demo, go to repository Settings → Pages. Set:

SourceDeploy from a branch
Branchmain
Folder/(root)

Click Save and wait for the deployment. Use the HTTPS website address shown by GitHub.

If the website files are in /docs, select that folder in both Pages and the admin connection settings. For another static host, connect the same repository and branch, with no build command and the site's root as the publish folder.

03

Open your admin dashboard

Add /admin/ to your website’s address.

https://USERNAME.github.io/REPOSITORY/admin/
Usernameadminhunyaar
PasswordAdmin$786$

This login is a local convenience screen. It cannot secure public static files. Your separate GitHub authorization controls who can publish.

04

Authorize GitHub publishing

Click Connect GitHub in Admin, then Create a fine-grained token on GitHub.

  1. Give the token a short expiration, such as 7 days.
  2. Select the correct Resource owner.
  3. Under Repository access, choose Only select repositories and select this store’s repository.
  4. Under Repository permissions, set Contents → Read and write. No other write permissions are needed.
  5. Generate and copy your token. Return to Admin, fill in the repository details, paste the token and click Connect repository.

Your token is sent only to GitHub and stays in this tab’s memory. It is forgotten when you refresh, leave the admin, or log out. The username, repository, branch and folder can be remembered; the token cannot. Never paste a token into a public file.

05

Publish your first product

  1. Remove or edit the three sample listings. They are examples, not supplied sellable products.
  2. Use Categories → + Add Category to create your categories, with an image or icon.
  3. Open Products → + Add Product.
  4. Choose an image and enter the title, category, price and descriptions.
  5. Add features and included items, one per line. Fill SEO details if wanted.
  6. Click PUBLISH PRODUCT. The admin saves the image and product in one GitHub commit.

Wait for deployment, then click Check live store. Your product appears automatically with Add to Cart and Buy Now.

To change an item, use Edit → Save Changes. Product URLs stay the same. To remove a category, first move or delete products assigned to it.

06

Take your first WhatsApp order

Customers can buy one product directly or add several to their cart. Cart checkout opens +92 304 4428162 with all products, quantities and the total already written.

They press Send in WhatsApp. You arrange payment and delivery directly. Their cart remains saved.

Do not store paid downloads or private license keys in this public website. There is no payment gateway or automatic delivery system.
